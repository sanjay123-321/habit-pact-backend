# Habit Pact — Backend

A Spring Boot REST API for Habit Pact, an app where two users pair up on a shared habit. 
The streak only continues if **both** users check in each day — if either misses a day, 
the streak resets for both.

## Tech Stack
- Java / Spring Boot
- Spring Data JPA
- MySQL
- Spring Security
